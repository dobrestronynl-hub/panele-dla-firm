# Publikacja jako portfolio na GitHub Pages

1. Połącz w ChatGPT integrację GitHub (wymaga Twojej autoryzacji) albo zaloguj się do serwisu GitHub samodzielnie.
2. Utwórz publiczne repozytorium `panele-dla-firm`, a następnie prześlij **zawartość folderu** `panele-dla-firm-github` do korzenia repozytorium, nie folder nadrzędny.
3. GitHub → repozytorium → Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. Docelowy URL: `https://TWOJ_LOGIN.github.io/panele-dla-firm/`. Potwierdzony login GitHub: `dobrestronynl-hub`.
5. Na swojej stronie DobreStrony.nl dodaj linki do branż, np. `/warsztat/`, `/budowa/` lub `/fryzjer/`.

To są demonstracje ze sztucznymi danymi. Nie ma tu kont użytkowników, serwera ani rzeczywistych płatności.
